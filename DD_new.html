1. クラスを選ぶ

Class（クラス）は「冒険者として何が得意な人なのか」を決めるものです。

Starting Equipment（開始装備）

2. Background / Species（出自・種族）

Terms（用語）Background（背景・出自）：冒険者になる前にどんな生活をしていたか。Species（種族）：ヒューマン、エルフ、ドワーフなど。Skill Proficiency（技能習熟）：その技能が得意で、判定に習熟ボーナスが加わります。Feat（特技）：キャラクターが持つ特別な能力。Language（言語）：キャラクターが理解できる言葉。

Background Equipment（背景の開始装備）

Language（言語）

Common（共通語）は全員が使えます。さらに2つ選びます。

3. Class Choices（クラス固有の選択）

Class Skill（クラス技能）：そのクラスが特に得意にできる技能。Cantrip（キャントリップ／初級呪文）：呪文スロットを使わずに使える基本的な魔法。Level 1 Spell（レベル1呪文）：より強力で、基本的には呪文スロットを使う魔法。

Class Skills（クラス技能）

4. Ability Scores（能力値）

Strength（筋力）＝力仕事、Dexterity（敏捷力）＝素早さ・器用さ、Constitution（耐久力）＝丈夫さ、Intelligence（知力）＝知識・推理、Wisdom（判断力）＝観察・直感、Charisma（魅力）＝人への影響力です。
