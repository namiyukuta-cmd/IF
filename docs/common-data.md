# IF 共通データの置き場所

新しいシナリオを素早く作るため、シナリオ作成前に必ず共通データを先に確認する。

## 共通データ

- アイテム: `data/dd-items.js`
- モンスター: `data/dd-monsters.js`
- NPC: `data/dd-npcs.js`
- クラス関連: `data/dd-class-options.js`
- 出自関連: `data/dd-origin-options.js`
- キャラクター共通データ: `data/dd-srd-character.js`

## シナリオ作成時のルール

1. 新しいアイテム・NPC・モンスターを書く前に、上記共通データに同じものがないか確認する。
2. 共通データにあるものは可能な限り再利用し、毎回ゼロから作らない。
3. シナリオ固有の人物・固有名付きボス・そのシナリオだけの特殊アイテムは `scenarios/<scenario-id>/` 側へ置く。
4. 今後、再利用できるアイテム・NPC・モンスターを追加したら、共通データにも追加して次のシナリオ作成に使えるようにする。
5. AIに新しいシナリオを作らせる場合も、最初にこのファイルと `docs/scenario-spec.md` を確認する。

このファイルは「次回から既存データを探し直さず、共通データを使ってシナリオ作成を開始する」ための固定メモとして扱う。
